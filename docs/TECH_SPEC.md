# Technical Specification

## Architecture

Frontend → REST API → Backend → Database

## Frontend

- React / Next.js
- TailwindCSS
- Axios for API calls

## Backend

- Node.js
- Express.js
- Prisma ORM
- JWT Authentication

## Database

- PostgreSQL
- Normalized relational schema

## Deployment Strategy

- Docker support
- Future cloud deployment (AWS / Vercel / Railway)

## Security

- Password hashing (bcrypt)
- JWT access tokens
- Role-based authorization

# CorePanel

CorePanel, küçük işletmeler için entegre bir satış ve yönetim paneli sağlar.  
Müşteriler, ürünlerini ekleyip, siparişlerini yönetebilirler.

## Özellikler:
- Kullanıcı yönetimi
- Ürün yönetimi
- Sipariş yönetimi
- Gerçek zamanlı analiz

## Teknolojiler:
- Node.js
- Express
- PostgreSQL
- Prisma ORM
- React (admin paneli için)

## Kurulum

1. Bu repo'yu bilgisayarınıza klonlayın:
    ```bash
    git clone https://github.com/myel2672/corepanel.git
    ```

2. Gerekli bağımlılıkları yükleyin:
    ```bash
    cd corepanel
    npm install
    ```

3. PostgreSQL veritabanını ayarlayın.

4. Uygulamayı başlatın:
    ```bash
    npm run dev
    ```

5. [http://localhost:5000](http://localhost:5000) adresinden çalıştığını kontrol edin.
